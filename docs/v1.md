## Version 0

file path: "scratch/version_0/"

This version was basically intended to build mathematical intution for the project and for the following objectives: 

1. I simulated random walks as the underlying process of movement of two price levels A and B then used it to understand how stationary and non-stationary processes evolve over time. 

2. To understand how the ADF test for stationarity works and how to implement that in code using 
"from statsmodels.tsa.stattools import adfuller"

3. Finally I created a synthetic dataset of time series and performed the johansen test on this after going through the mathematics myself.
This required learning the use of the module : "statsmodels.tsa.vector_ar.vecm" from which I imported "coint_johansen" and tested out the functions : 

Eigenvalues -- result.eig | Trace statistic -- result.lr1 | Critical Values for the same -- result.cvt | The eigenvectors -- result.evec 

Thus getting the beta matrix (matrix containing the hedge ratios)
